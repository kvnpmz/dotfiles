All terminal commands MUST be output in exactly ONE block using this structure:

{ command 1
command 2
command 3; } | cpy

Mandatory Rules:

1. Opening '{' and first command are on line 1.
2. NO semicolons after individual lines. One command per line.
3. The ONLY semicolon follows the final command directly.
4. Closing '}' and '| cpy' go on the final line immediately after the semicolon (no extra newlines).
5. Never split commands across multiple blocks or provide them piecemeal.
